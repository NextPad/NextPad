# Herkunft der eingebetteten Dateien

- `quicksand.ttf`: Schrift Quicksand (variabel), SIL Open Font License 1.1, siehe `quicksand-OFL.txt`; Quelle github.com/google/fonts (ofl/quicksand).
- `icons.woff`: Symbolschrift `fontawesome-etherpad` aus Etherpad (github.com/ether/etherpad-lite, Apache-2.0), abgeleitet aus Font Awesome (SIL OFL für die Glyphen).
- `fond.jpg`: Hintergrundbild der Etherpad-Startseite (Skin Colibris, Etherpad, Apache-2.0).
- `editor.js`, `editor.css`: aus `web/` gebaut (siehe dort). Die Daumen-Symbole der Bewertung folgen den Symbolen `thumbs-up`/`thumbs-down` von Lucide (lucide.dev, ISC-Lizenz, © Lucide Contributors).
- `fonts/NotoEmoji.ttf`: Schrift Noto Emoji (einfarbig, variabel) für Emoji im PDF, SIL Open Font License 1.1, siehe `fonts/NotoEmoji-OFL.txt`; Quelle github.com/google/fonts (ofl/notoemoji).
- `fonts/web/nextpad-sans-*.woff2`: Liberation Sans 2.1.5 (Regular, Bold, Italic), auf lateinische Zeichen verkleinert und als „NextPad Sans“ umbenannt, weil die SIL Open Font License 1.1 veränderten Fassungen die reservierten Namen „Liberation“, „Arimo“, „Tinos“ und „Cousine“ verbietet; siehe `fonts/web/LiberationSans-OFL.txt`; Quelle github.com/liberationfonts/liberation-fonts.
- `fonts/web/lexend.woff2`: Schrift Lexend (variabel), auf lateinische Zeichen verkleinert, SIL Open Font License 1.1, siehe `fonts/web/Lexend-OFL.txt`; Quelle github.com/google/fonts (ofl/lexend).
