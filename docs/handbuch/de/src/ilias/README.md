# In ILIAS einbinden

<aside class="np-kasten np-ziel" aria-label="Worum es geht">
<p class="np-kasten-titel">Worum es geht</p>

- Pad, Ideensammlung oder Quiz als Objekt in einen ILIAS-Kurs legen
- wissen, wer hineinkommt und wer moderiert
- NextPad einmal für die ganze ILIAS-Installation eintragen

</aside>

NextPad lässt sich als Objekt in einen ILIAS-Kurs oder eine Gruppe legen. Die Administration trägt NextPad dafür einmal als LTI-Provider ein. Danach legen Lehrende das Objekt an wie einen Weblink oder eine Datei. Wer es startet, ist über ILIAS schon angemeldet. Ein eigenes Konto bei NextPad braucht niemand.

<aside class="np-kasten np-begriffe" aria-label="Begriffe vorab">
<p class="np-kasten-titel">Begriffe vorab</p>

<dl>
<dt>LTI-Konsument</dt><dd>das Objekt in ILIAS für Werkzeuge, die auf einem anderen Server laufen.</dd>
<dt>LTI-Provider</dt><dd>so nennt ILIAS das eingetragene Werkzeug, hier NextPad.</dd>
<dt>LTI</dt><dd>der Standard, über den ILIAS die Anmeldung an NextPad weitergibt. Passwörter verlassen ILIAS dabei nicht.</dd>
<dt>Leitung</dt><dd>Kursadministration und Kursbetreuung, in Gruppen die Gruppenadministration. Sie moderieren das Objekt in NextPad.</dd>
</dl>
</aside>

## Im Kurs anders als auf der Startseite

| | Über die Startseite | Als Objekt im Kurs |
|---|---|---|
| Zugang | Link oder QR-Code, ohne Konto | nur Kursmitglieder über das Objekt |
| Moderation | der Browser, in dem angelegt wurde | Kursadministration und Kursbetreuung |
| QR-Code auf der Leinwand | führt direkt in die Sammlung | führt zum Objekt in ILIAS, dort folgt die Anmeldung |
| Sprache | Auswahl „DE \| EN“, sonst Browser | Auswahl „DE \| EN“, sonst Sprache aus ILIAS |

## Die zwei Anleitungen

1. [Objekt im Kurs anlegen](objekt.md): für Lehrende, am Beispiel einer Ideensammlung.
2. [Werkzeug in ILIAS eintragen](einrichten.md): für die Administration der ILIAS-Installation, einmal je Werkzeug.

Die Bilder stammen aus einer frisch installierten ILIAS 11. Andere Versionen und Designs sehen etwas anders aus, die Wege sind dieselben. QR-Code und „Zurück zum Kurs“ führen ab NextPad 0.19 nach ILIAS.
