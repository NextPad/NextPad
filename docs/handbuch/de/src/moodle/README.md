# In Moodle einbinden

<aside class="np-kasten np-ziel" aria-label="Worum es geht">
<p class="np-kasten-titel">Worum es geht</p>

- Pad, Ideensammlung oder Quiz als Aktivität in einen Moodle-Kurs legen
- wissen, wer hineinkommt und wer moderiert
- NextPad einmal für die ganze Moodle eintragen

</aside>

NextPad lässt sich als Aktivität in einen Moodle-Kurs legen. Die Administration trägt NextPad dafür einmal als externes Tool ein. Danach legen Lehrende die Aktivität an wie ein Forum oder eine Aufgabe. Wer sie startet, ist über Moodle schon angemeldet. Ein eigenes Konto bei NextPad braucht niemand.

<aside class="np-kasten np-begriffe" aria-label="Begriffe vorab">
<p class="np-kasten-titel">Begriffe vorab</p>

<dl>
<dt>Externes Tool</dt><dd>die Aktivität in Moodle für Werkzeuge, die auf einem anderen Server laufen.</dd>
<dt>LTI</dt><dd>der Standard, über den Moodle die Anmeldung an NextPad weitergibt. Passwörter verlassen Moodle dabei nicht.</dd>
<dt>Leitung</dt><dd>die Lehrenden des Kurses, auch ohne Bearbeitungsrecht. Sie moderieren die Aktivität in NextPad.</dd>
</dl>
</aside>

## Im Kurs anders als auf der Startseite

| | Über die Startseite | Als Aktivität im Kurs |
|---|---|---|
| Zugang | Link oder QR-Code, ohne Konto | nur Kursmitglieder über die Aktivität |
| Moderation | der Browser, in dem angelegt wurde | die Lehrenden des Kurses |
| QR-Code auf der Leinwand | führt direkt in die Sammlung | führt zur Aktivität in Moodle, dort folgt die Anmeldung |
| Sprache | Auswahl „DE \| EN“, sonst Browser | Auswahl „DE \| EN“, sonst Sprache aus Moodle |
