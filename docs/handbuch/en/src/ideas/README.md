# Idea collection

<aside class="np-kasten np-ziel" aria-label="What this is about">
<p class="np-kasten-titel">What this is about</p>

- create an idea collection with your own question
- show the group's entries and votes on the projector
- moderate and save the collection

</aside>

The idea collection is a list where everyone adds ideas or questions without a name. Each entry can be voted for. This shows what concerns the group most. Students need no account and no app, only a mobile device, internet access and the QR code.

<aside class="np-kasten np-begriffe" aria-label="Terms first">
<p class="np-kasten-titel">Terms first</p>

<dl>
<dt>Host</dt><dd>the person who created the collection. Only they set the question and moderate.</dd>
<dt>Entry</dt><dd>an idea or question, at most 500 characters, without a name.</dd>
<dt>Vote</dt><dd>agreement with an entry. Each person has one vote per entry and can take it back.</dd>
<dt>Board</dt><dd>the large view for the projector with the six most popular open entries and the QR code.</dd>
<dt>Take part</dt><dd>the page of the collection with the input field and the list, as participants see it.</dd>
<dt>Editing view</dt><dd>the same page for the host, with the moderation buttons in addition.</dd>
</dl>
</aside>

## The two guides

1. [Create an idea collection](create.md): enter the question, open the board with the QR code.
2. [Collect and moderate](collect.md): entries from phones, votes, mark as done, hide, save.

The example in the films collects questions for the next session of a seminar on women artists.
