# Embed in ILIAS

<aside class="np-kasten np-ziel" aria-label="What this is about">
<p class="np-kasten-titel">What this is about</p>

- add a pad, idea collection or quiz to an ILIAS course as an object
- know who gets in and who moderates
- register NextPad once for the whole ILIAS installation

</aside>

NextPad can be added to an ILIAS course or group as an object. For this the administration registers NextPad once as an LTI provider. Teachers then add the object like a weblink or a file. Whoever starts it is already signed in through ILIAS. Nobody needs a NextPad account.

<aside class="np-kasten np-begriffe" aria-label="Terms first">
<p class="np-kasten-titel">Terms first</p>

<dl>
<dt>LTI Consumer</dt><dd>the ILIAS object for tools that run on another server.</dd>
<dt>LTI provider</dt><dd>what ILIAS calls the registered tool, here NextPad.</dd>
<dt>LTI</dt><dd>the standard ILIAS uses to pass the sign-in on to NextPad. Passwords never leave ILIAS.</dd>
<dt>Lead</dt><dd>course administrators and course tutors, in groups the group administrators. They moderate the object in NextPad.</dd>
</dl>
</aside>

## A course differs from the start page

| | From the start page | As a course object |
|---|---|---|
| Access | link or QR code, no account | course members only, through the object |
| Moderation | the browser it was created in | course administrators and course tutors |
| QR code on the board | leads straight to the collection | leads to the object in ILIAS, where sign-in follows |
| Language | choice “DE \| EN”, otherwise the browser | choice “DE \| EN”, otherwise the ILIAS language |

## The two guides

1. [Add an object to a course](object.md): for teachers, using an idea collection as the example.
2. [Register the tool in ILIAS](setup.md): for the administration of the ILIAS installation, once per tool.
