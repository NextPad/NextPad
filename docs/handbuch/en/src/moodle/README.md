# Embed in Moodle

<aside class="np-kasten np-ziel" aria-label="What this is about">
<p class="np-kasten-titel">What this is about</p>

- add a pad, idea collection or quiz to a Moodle course as an activity
- know who gets in and who moderates
- register NextPad once for the whole Moodle site

</aside>

NextPad can be added to a Moodle course as an activity. For this the administration registers NextPad once as an external tool. Teachers then add the activity like a forum or an assignment. Whoever starts it is already signed in through Moodle. Nobody needs a NextPad account.

<aside class="np-kasten np-begriffe" aria-label="Terms first">
<p class="np-kasten-titel">Terms first</p>

<dl>
<dt>External tool</dt><dd>the Moodle activity for tools that run on another server.</dd>
<dt>LTI</dt><dd>the standard Moodle uses to pass the sign-in on to NextPad. Passwords never leave Moodle.</dd>
<dt>Lead</dt><dd>the teachers of the course, including non-editing teachers. They moderate the activity in NextPad.</dd>
</dl>
</aside>

## A course differs from the start page

| | From the start page | As a course activity |
|---|---|---|
| Access | link or QR code, no account | course members only, through the activity |
| Moderation | the browser it was created in | the teachers of the course |
| QR code on the board | leads straight to the collection | leads to the activity in Moodle, where sign-in follows |
| Language | choice “DE \| EN”, otherwise the browser | choice “DE \| EN”, otherwise the Moodle language |
