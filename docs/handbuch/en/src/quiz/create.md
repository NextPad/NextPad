## Steps

1. On the start page choose **Quiz grid**.
2. Enter a **title**.
3. Enter the **teams**, separated by commas.
4. Enter the **time per question** in seconds. 0 means no countdown.
5. Paste the **questions as a table**. Each row is one question: category, points, question, answer.
6. Choose **Save**. The grid is ready. Only the host sees the answers.
7. Open the **QR code** from the menu. Phones scan it and join without an account.

Later, **Edit questions** in the menu changes the grid.

## Two ways to enter the table

- **Markdown table**, as in the film: columns are separated by `|`.
- **From a spreadsheet**: in Excel, LibreOffice Calc or Numbers, select the four columns, copy and paste.

A header row is not needed. If there is one, it is skipped.
