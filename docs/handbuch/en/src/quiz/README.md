# Quiz grid

<aside class="np-kasten np-ziel" aria-label="What this is about">
<p class="np-kasten-titel">What this is about</p>

- create a quiz grid for your own course
- check beforehand whether the buzzer scores fairly in the room
- run a quiz on the projector and award points

</aside>

The quiz grid is a guessing game for the projector. Categories are in columns, point values in rows. Teams buzz with their phones. Students need no account and no app, only a mobile device, internet access and the QR code.

<aside class="np-kasten np-begriffe" aria-label="Terms first">
<p class="np-kasten-titel">Terms first</p>

<dl>
<dt>Host</dt><dd>the person at the computer who runs the quiz. Only they see the answers.</dd>
<dt>Grid</dt><dd>the table of categories and point values on the projector.</dd>
<dt>Field</dt><dd>a cell in the grid. Behind each field is a question.</dd>
<dt>Buzzer</dt><dd>the large button on the phone. Whoever presses first may answer.</dd>
<dt>Clock sync</dt><dd>Every phone keeps setting its clock by the server. So the moment of the press counts, not when the press arrives.</dd>
</dl>
</aside>

## The three guides

1. [Create a quiz](create.md): enter title, teams, time per question and questions.
2. [Measure the buzzer](measure-buzzer.md): before the first use in a room, check whether the clock sync holds.
3. [Run the quiz](run.md): let teams choose, open fields, award points.

The example in the films asks about women artists the canon left out. It spans the Baroque to Modernism.
