# About this manual

This manual describes NextPad from a teaching point of view: what can be prepared, how a session runs and what remains afterwards.

- **Getting started** leads from the first pad to a shared address.
- **Guides** show single tasks step by step, with a short film and a list of steps.
- **Teaching scenarios** combine several tools into one teaching situation.
- **Reference** collects keyboard shortcuts and settings.
- **Operation** is for everyone who runs NextPad on their own server.

Each guide starts with its goals. The films play muted on their own while they are in view. Clicks and soft music can be switched on in the player. The sound shows nothing that is not also in the picture. With the setting “Reduce motion” turned on, the still image stays. Every film can be paused. Below each film the same sequence is listed as steps.
